   name the row to land and what to withdraw (Task 2).
2. **No skip.** The test environments hold every distribution the triggers read, and a
   test that cannot find one must fail, never skip (`AGENTS.md`, "A suite that skips is a
   suite that passes") (Task 2).
3. **Provenance.** Each 🔎 is the first pull request to write the item, not to give it
   today's title (Task 3).
4. **Renumbering.** Appending rows 8 to 11 renumbers nothing, and `check-spec-renumbering`
   passes (Task 3).
5. **The labels.** Every 🎫 carries `spec: open item`, and the nightly drift finds every
   labelled issue cited (Task 3, Task 4).
