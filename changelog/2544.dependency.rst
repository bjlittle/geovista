Migrated from ``vtk-xref`` to `sphinx-vtk-xref
<https://github.com/pyvista/vtk-xref>`__ and bumped it from ``0.1.2`` to
``0.4.0``. It is the same sphinx extension under a renamed ``PyPI``
distribution, so the ``conf.py`` ``extensions`` entry is renamed ``vtk_xref``
to ``sphinx_vtk_xref`` to match. The old name stopped at ``0.1.2``, so neither
``pixi`` nor ``dependabot`` could see the three releases that followed under
the new one.

``0.1.2`` warned whenever it could not reach ``vtk.org`` to validate a
``:vtk:`` class reference, cached that class as invalid, then warned again for
every remaining reference to it, so one network blip was enough to fail the
documentation build under ``--fail-on-warning``. ``0.4.0`` reports an
unreachable check as transient and uses the class URL unvalidated. Closes
:issue:`2541`. (:user:`claude`)
